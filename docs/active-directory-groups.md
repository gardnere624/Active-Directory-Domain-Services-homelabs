# Active Directory Group Configuration

## IT-Announcements Distribution Group

The `IT-Announcements` group was created to distribute announcements to IT personnel.

### Configuration

- Group name: `IT-Announcements`
- Group scope: Universal
- Group type: Distribution
- Description: Contains all IT member accounts for announcements
- Domain: `home.lab`



### Membership

The group contains the appropriate IT and administrative accounts required to receive announcements.
